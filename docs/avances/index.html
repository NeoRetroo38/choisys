Backend de choisys · avances · 4/12

Mi cuenta (RGPD)

Cada persona ve y controla solo lo suyo.

  • GET /me → perfil + capacidades
  • GET /me/runs y /me/export → mi historial y mis datos
  • POST /me/profile → cambiar mi nombre
  • POST /me/delete → borrar cuenta (pide contraseña; requisito de Apple)
Backend de choisys · avances · 5/12

Operación sudev

Solo el rol más alto, y siempre por debajo de sí mismo.

  • Listar perfiles con número de recorridos
  • Asignar rol, con motivo y auditoría en la misma transacción
  • Desactivar o reactivar cuentas
  • Nadie se cambia a sí mismo, toca a un igual ni sube a otro a su nivel
Backend de choisys · avances · 6/12

El historial se guarda

Al terminar las 3 fases, la API guarda el recorrido.

  • Solo lo que devuelve el motor: 3 mediciones (fase, fila, columna)
  • Si guardar falla, la respuesta a la persona no se rompe
  • Reintentos no duplican
  • TypeScript no calcula nada del Cubo
